**Solaris Drift: Sunset Keys** — an original, 100% offline desktop browser open-world coastal crime game set in **Palmera City, State of Solaria**, featuring a neon-sunset 2.5D/3D-perspective coastal metropolis and an iOS 27 Liquid Glass HUD.

## Features
- **6 Coastal Districts**: Explore *Coral Drive Strip*, *Mariposa Marina*, *Solaria Downtown*, *Caiman Keys Causeway*, *Flamingo Heights*, and *Port Aurelia Docks* on foot and behind the wheel.
- **7 Original Vehicles & Carjacking (`F`)**: Steal and drift the *Solaria GT-R*, *Veloce Apex*, *Palmera Cruiser*, *Caiman 4x4*, *Aurelia Heist Van*, *SPPD Interceptor*, and *SPPD SWAT Enforcer* with handbrake drifting (`Space`), skidmarks, headlight cones, nitro boost (`Shift`), and Neon Respray garages (`$500`).
- **5-Star SPPD Wanted System**: Escalating police response with flashing red/blue lightbar pavement reflections, pit maneuvers, armored SWAT vans, evasion cooldowns, and pursuit helicopter searchlights.
- **6-Mission Story Campaign & Combat**: Follow *Mateo Vance* and *Elena Vega* across six coastal crime missions with a 5-weapon arsenal (`1–5`), tracers, muzzle flashes, explosions, and pedestrian/syndicate AI.
- **iOS 27 Liquid Glass HUD & 3-Slot Save System**: Frosted-glass GPS radar minimap, wanted stars, vehicle telemetry, procedural Web Audio SFX & 3-station Solaria FM radio (`Q`), persistent `localStorage` save slots (`F5` / `M`), and JSON export/import.

## Run it

```sh
node serve.ts
# Open http://localhost:8080 in desktop Chrome
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
